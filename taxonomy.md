# OKF Taxonomy

## Domain Taxonomies

### Knowledge Categories
- `engineering`: Software design, backend, frontend, systems, and algorithms.
- `ai_agentic`: AI agents, LLM orchestration, multi-agent systems, tools, RAG.
- `medical_fhir`: Healthcare records, FHIR standards, clinical documentation.
- `agriculture`: Farming, organic practices, crop advisory.
- `finance`: Trading, financial markets, technical analysis.

### Tag Classifications
- `core`: Foundational concept or framework feature.
- `workflow`: Process orchestration, DAGs, pipeline components.
- `tooling`: Deterministic tool, VM sandbox, file system helper.
- `memory`: Knowledge retention, database, logic-based Prolog memory.
